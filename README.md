# Batuhan Tunca portfolio

Static site: `index.html` plus the `assets/` folder. No build step.

## Publish with GitHub Pages
1. Put `index.html` and `assets/` at the top level of the repository and push to `main`.
2. On GitHub: Settings > Pages > Source "Deploy from a branch" > `main` and `/ (root)` > Save.
3. The site appears at `https://<username>.github.io/<repo>/` after a minute or two.

Fonts load from Google Fonts. Everything else is local.
